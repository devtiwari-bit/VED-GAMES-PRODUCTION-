## About the website

The site is the home of Ved Games Production. It has four pages:

- **Home:** the studio, featured games and upcoming games
- **Games:** all live games, with Play Now and Share buttons
- **About:** the studio and its owner
- **Join us:** a form for people who want to help make games

It is built with plain HTML, CSS and JavaScript, so it runs free on GitHub Pages. It works on phones, tablets and computers, and includes SEO tags, a sitemap and a favicon.
